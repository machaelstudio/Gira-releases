# Gira — installers

Downloads for the Gira tour-management app. The source code lives in the `Gira` repository; this repository only hosts release builds.

## macOS

Download the latest `Gira-<version>-universal.dmg` from the **Releases** page. It runs on Apple Silicon and Intel Macs and is signed and notarized by Apple, so it opens like any other app.

1. Open the `.dmg` and drag **Gira** to Applications.
2. On first launch, open **Gira → Server URL…** (⌘,) and enter the address of your team's Gira server. The default is `http://localhost:3040`, which only works on a machine running the backend.

## iOS

The iOS app is distributed through TestFlight; ask the tour office for an invite.
